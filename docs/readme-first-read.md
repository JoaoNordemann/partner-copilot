# Leitura rápida do README

Um agente de IA sem contexto prévio leu a abertura até os comandos como leitor de primeira viagem. A leitura identificou o público, o uso de avaliações sintéticas e a resposta com fontes.

- Termos como recall limitado, teto, QLoRA e erro 502 dificultaram a leitura da tabela. A revisão explica as duas métricas de busca e descreve as rejeições em linguagem direta.
- O resultado 3/19 era difícil de interpretar. A tabela agora explica que se tratava de devolver uma lista vazia quando nenhum aspecto se aplicava.
- A mediana da API deixava em dúvida se incluía falhas. A tabela explicita os sucessos e as rejeições incluídos.
- Os comandos em CPU sugeriam geração ao vivo. A distinção entre simulação, respostas gravadas e geração em GPU agora aparece antes dos comandos. A abertura também ganhou uma pergunta de exemplo.

## Leitura humana

Feedback encaminhado por João. A pessoa entendeu que o projeto analisa avaliações para orientar melhorias em cada estabelecimento. A tabela trouxe métricas, mas o passo a passo que produziu os resultados ficou obscuro. A leitura identificou o objetivo do produto, enquanto o resultado do teste externo ficou fora do resumo do leitor.

A abertura passou a explicar o fluxo da ingestão à validação e a dizer como foram feitas as comparações. Também explicita o achado do teste de e-commerce antes da tabela. A abertura revisada ainda não passou por uma segunda leitura.
